# EducationalApp

Prototype backend for an educational study app with Pomodoro, study history, goals, progress stats, coins, and missions.

## Backend

Path:

```text
backend/
```

Run locally:

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

API base URL:

```text
http://localhost:8080
```

Demo login:

```json
{
  "email": "demo@educational.app",
  "password": "123456"
}
```

H2 console:

```text
http://localhost:8080/h2-console
```

H2 settings:

```text
JDBC URL: jdbc:h2:mem:educationalapp
User: sa
Password:
```
